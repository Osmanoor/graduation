Arabic RAG Query Enhancement 3 / 11
Phase 4 Experiments

What We Accomplished

Goal: Address identified gaps and build on Query2Doc with corpus-steered expansion
1. BM25 Query Repetition (Exp 1.1)
  • Fixed term dilution for all 9 models
  • Tested fixed (n=1,3,5,7,10) and adaptive (β=2,4,6) repetition
  • Best: Aya 8B β=2 → 0.5855 (+26.7% over BM25)
2. Hybrid Retrieval Fusion (Exp 1.2)
  • Combined BM25 + Dense with RRF and CC fusion
  • Tested α sweep (0.1–0.9) and k values (20, 60)
  • Best: RRF k=20 → 0.6267 (+35.6% over BM25)
3. Corpus-Steered QE (Exp 013)
  • Ground LLM expansions in first-pass retrieved docs
  • Tested corpus-only, blind-only, and combined (2+2)
  • Best: BM25+CSQE → 0.6157 (+33.2% over BM25)
4. CSQE + Hybrid Fusion (Exp 2.1)
  • Three configs: A (BM25+CSQE + Dense), B (BM25 + Dense+CSQE), C (both+CSQE)
  • Tested RRF and CC fusion for each config
  • Best: Config A RRF → 0.7137 (+54.5% over BM25)
5. Per-Query Error Analysis
  • Analyzed all 2,896 queries individually
  • 56.8% improved, 26.6% tie, 16.6% regressed
  • Identified Type A (52%) and Type B (36%) regression causes
Final Best Result:
  • 0.7137 nDCG@10
  • +54.5% over BM25 baseline
  • +13.9% over hybrid baseline

Arabic RAG Query Enhancement 5 / 11
Key Findings

Phase 4: What We Learned

  1. Query Repetition Fixes BM25
    • All 9 models recovered with β=2 or n=5-7
    • Aya 8B: 0.5855 (+26.7% over BM25)
    • Simple fix, massive impact
  2. Hybrid Fusion is Powerful
    • RRF k=20: 0.6267 (+35.6%)
    • No QE needed for strong baseline
    • BM25 + Dense are complementary
  3. Corpus Grounding Works
    • CSQE: 0.6157 on BM25 alone
    • Prevents hallucinations (1,061 big wins)
    • First-pass quality is key predictor
  1. Asymmetric QE is Optimal
    • Apply CSQE to BM25 only
    • Dense encoder degrades on long queries
    • Config A (0.7137) > Config C (0.6936)
  2. Error Analysis Insights
    • 56.8% queries improved
    • Short queries gain most (+0.1990)
    • 367 regressions: 52% Type A, 36% Type B
Novel Contribution:
  • First corpus-steered QE for Arabic
  • Retriever-specific QE strategy
  • Comprehensive 10-model comparison
