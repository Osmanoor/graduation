# Thesis Writing Guidelines

## Template Location
`University_of_Khartoum__EEE_bachelor_s_thesis_template/`

## When Writing Thesis Content

### Source Your Claims
- **Methodology claims:** Reference `research_decisions/technical_specifications.md`
- **Decision rationale:** Reference `meetings/6.1.2026_meeting_outcomes.md`
- **Experiment results:** Reference specific files in `experiments/`
- **Literature:** Reference papers in `papers/`

### Do NOT
- Invent experiment results not in `experiments/` folder
- Claim decisions that aren't in the meeting outcomes
- Add citations without corresponding paper summary in `papers/`

### Chapter 2 (Literature Review)
- Already drafted: `meetings/chapter2_initial_draft.md`
- Generated version: `University_of_Khartoum__EEE_bachelor_s_thesis_template/Chapters/chapter2_generated.tex`
- Update as we read more papers

### Methodology Chapter
- Base on `research_decisions/technical_specifications.md`
- Only describe what we actually implemented

### Results Chapter
- Only include results from documented experiments in `experiments/`
- Include exact metric values from experiment docs
- Do NOT extrapolate or predict results

## Writing Style
- Academic but clear
- Cite sources properly (BibTeX)
- Acknowledge limitations honestly
