# Literature Search Guide

## Search Strategy

**Primary Sources:**
- arXiv (cs.CL, cs.IR categories)
- ACL Anthology
- Semantic Scholar

**Useful Search Terms:**
- "query enhancement" AND "retrieval"
- "Arabic" AND "information retrieval"
- "MIRACL" AND "query"
- "HyDE" OR "query rewriting"
- "dense retrieval" AND "multilingual"

## Evaluation Criteria

Before adding a paper, check:

1. **Recency:** 2022-2025 preferred
2. **Relevance:** About query-side improvements (not document-side)
3. **Metrics:** Reports retrieval metrics (Recall, NDCG, MRR)
4. **Reproducibility:** Code available is a plus

## Output

Save to: `papers/[YEAR]_[Short Title].md`

Follow the template in `.claude/contexts/paper-analysis.md`.

## Do NOT
- Add papers without proper analysis
- Assume techniques work for Arabic without evidence
- Skip the relevance assessment section
