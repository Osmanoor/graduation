# Paper Analysis Guidelines

## When Creating Paper Summaries

Use this exact structure:

```markdown
# [Paper Title]
**Year:** [Year]
**Authors:** [Authors]
**Venue:** [Conference/Journal]

## Short Description
[2-3 sentences]

## Research Question
[What problem does this paper address?]

## Main Methodology
[How did they solve it?]

## Dataset & Benchmark
[What data did they use? Any overlap with MIRACL?]

## Key Results
[Main findings with numbers if available]

## Relevance to Our Project
- **Applicable to Arabic?** [Yes/No/Maybe - explain]
- **Uses MIRACL?** [Yes/No]
- **Retrieval metrics reported?** [Which ones]
- **Feasible for us?** [Consider Colab constraints]

## Notes
[Any other observations]
```

## Do NOT
- Invent paper details not in the source
- Assume applicability without evidence
- Add papers to literature review without this analysis
