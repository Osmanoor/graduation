- **Short Description:**
This paper introduces "Rewrite-Retrieve-Read," a novel framework for retrieval-augmented Large Language Models (LLMs) that focuses on adapting the search query rather than tuning the retriever or reader. The approach employs a small, trainable language model to rewrite user inputs into effective search queries, optimizing the system for frozen black-box LLMs and web search engines via reinforcement learning.

- **Research Question:**
How can the performance of retrieval-augmented generation be enhanced when both the retrieval module (web search) and the reader (LLM) are frozen black boxes, specifically addressing the semantic gap between the original input text and the effective query required to retrieve necessary external knowledge?

- **Main Methodology:**
The authors propose a pipeline where a "rewriter" module processes the input before it reaches the retriever. They utilize a small language model (T5-large) as this trainable rewriter, while the retriever (Bing Search) and reader (ChatGPT/Vicuna) remain frozen. The rewriter is optimized in a two-stage process: first, it undergoes warm-up training using pseudo-data generated by an LLM; second, it is fine-tuned using Reinforcement Learning (specifically Proximal Policy Optimization) where the reward signals are derived from the frozen LLM reader's performance accuracy on the downstream task.

- **Dataset & Benchmark:**
*   **Datasets:** Open-domain QA datasets (HotpotQA, AmbigNQ, PopQA) and a Multiple-choice QA dataset (MMLU).
*   **Metrics:** Exact Match (EM), F1 Score, and Retrieval Hit Rate.

- **Research Contributions:**
The primary contribution of this work is the shift in optimization focus for Retrieval-Augmented Generation (RAG) systems from the heavy reader or retriever models to the query formulation stage. By introducing the "Rewrite-Retrieve-Read" framework, the authors provide a solution for scenarios where the underlying LLM and search engines are "black boxes" (accessible only via API) and cannot be fine-tuned. This fills a technical gap in aligning frozen, disparate modules by utilizing a lightweight, trainable intermediary to bridge the difference between user intent and search engine requirements.

Furthermore, the paper validates a resource-efficient training scheme that enables a small language model (T5-large) to significantly boost the performance of massive LLMs (like ChatGPT). The findings demonstrate that using reinforcement learning to align the rewriter with the reader’s feedback allows the system to handle complex multi-hop reasoning and ambiguity better than standard "retrieve-then-read" pipelines. This proves that small, tunable models can effectively steer large, frozen systems, offering a scalable alternative to end-to-end training of massive models.
