# BGE-M3: Multi-Lingual, Multi-Functionality, Multi-Granularity Text Embeddings
**Year:** 2024
**Authors:** Jianlv Chen, Shitao Xiao, Peitian Zhang, Kun Luo, Defu Lian, Zheng Liu
**Venue:** ACL 2024
**arXiv:** 2402.03216

## Short Description
M3-Embedding achieves unprecedented versatility in multi-linguality (100+ languages), multi-functionality (dense, sparse, multi-vector retrieval), and multi-granularity (up to 8192 tokens). Uses novel self-knowledge distillation where different retrieval methods reinforce each other during training.

## Research Question
How to create a single embedding model that supports multiple languages, multiple retrieval methods (dense, sparse, ColBERT), and multiple input lengths in one unified model?

## Main Methodology

### Architecture
- Base: XLM-RoBERTa (~568M parameters)
- Pre-trained with RetroMAE method
- Extended max position to 8192 tokens
- Embedding dimension: 1024

### Three Retrieval Methods in One Model
1. **Dense Retrieval:** [CLS] token embedding, cosine similarity
2. **Sparse/Lexical Retrieval:** Learned term weights (like neural BM25)
3. **Multi-Vector Retrieval:** ColBERT-style late interaction

### Self-Knowledge Distillation (Key Innovation)
- Combine scores from all three retrieval methods as teacher signal
- Formula: `s_inter = w1·s_dense + w2·s_lex + w3·s_mul`
- Each method learns from the ensemble, improving all

### Training Pipeline
1. **Pre-training:** RetroMAE on 1.2B multilingual text pairs
2. **Fine-tuning:** Self-knowledge distillation with labeled data
3. **Efficient batching:** Group by sequence length, gradient checkpointing

## Dataset & Benchmark

### Training Data
- **Unsupervised:** 1.2B text pairs, 194 languages, 2655 cross-lingual correspondences
- **Sources:** Wikipedia, S2ORC, xP3, mC4, CC-News, NLLB, CCMatrix
- **Fine-tuning:** MS-MARCO, HotpotQA, NQ, MIRACL, Mr.TyDi, DuReader

### Evaluation Benchmarks
- MIRACL (18 languages) - multilingual retrieval
- MKQA (25 languages) - cross-lingual retrieval
- MLDR (13 languages) - long document retrieval
- NarrativeQA - English long-doc

## Key Results

### MIRACL Arabic (nDCG@10)
| Method | Score |
|--------|-------|
| BM25 | 39.5 |
| mDPR | 49.9 |
| mContriever | 52.5 |
| mE5-large | 76.0 |
| E5-mistral-7b | 73.3 |
| **BGE-M3 Dense** | **78.4** |

| BGE-M3 Multi-vec | 79.6 |

## Relevance to Our Project

- **Applicable to Arabic?** ✅ Yes - Explicitly tested on MIRACL Arabic with state-of-the-art results (80.2 nDCG@10)
- **Uses MIRACL?** ✅ Yes - Both in training (fine-tuning) and evaluation
- **Retrieval metrics reported?** nDCG@10, Recall@100 (matches our metrics)
- **Feasible for us?** ⚠️ Tight fit on free Colab (568M params, ~2-3GB VRAM), but doable with batch size 16 and overnight runs

### Specific Benefits for Our Project
1. **Multi-functionality:** Can compare BGE-M3's sparse vs standalone BM25
2. **Arabic performance:** Best reported results on MIRACL Arabic
3. **Long context:** 8192 tokens handles long Arabic Wikipedia passages
4. **Widely cited:** Used as baseline in many 2024-2025 papers

### Potential Concerns
1. Large model size may require careful memory management on free Colab
2. Embedding 2.1M passages will take ~12-15 hours
3. Multi-vector retrieval is computationally expensive (use as reranker only)

## Notes

### Ablation Study Findings
- Self-knowledge distillation improves all methods (especially sparse: 36.7 → 53.9)
- RetroMAE pre-training adds +5.6 nDCG@10
- Unsupervised pre-training adds +3.1 nDCG@10

### Hybrid Retrieval Weights (from paper)
- For MIRACL: w1=1, w2=0.3, w3=1 (dense + sparse + multi-vec)
- For long-doc: w1=0.2, w2=0.8, w3=0 (sparse dominates)
