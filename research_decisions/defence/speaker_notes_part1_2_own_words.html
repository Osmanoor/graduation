The problem statement, and what we are not doing

We want to be clear that we don't want to solve the Arabic problems — the morphological problems, the lexical problems, the problems that we stated. We want to improve the information retrieval in general.

We know that query enhancement applies to English and is validated very clearly. But we don't know if it intuitively applies to the Arabic language as well, because the Arabic language doesn't match the English language. It has its own problems, like the ones we listed.

So our key problem statement is this: because of the Arabic challenges, we want to explore to what extent the query enhancement techniques apply to the Arabic language, and to what extent they do improve the performance of information retrieval.

The literature in English has a solution to the information retrieval problem, which is query enhancement — but the Arabic literature is a bit poor in that side. We seek to find the answer to: to what extent does query enhancement improve the information retrieval in an Arabic RAG system?
